# Return to Skating — 13 semanas v2

Aplicación web estática para acompañar 645 por la mañana y un programa progresivo de patinaje por la tarde.

## Incluye
- 13 semanas / 6 sesiones por semana.
- Ejercicios concretos, dosis, tiempos, repeticiones y criterios.
- Seguimiento por ejercicio con casillas persistentes.
- Dashboard de progreso global y semanal.
- Skill Tracker con pruebas en semanas 1, 4, 8 y 13.
- Training Log para fecha, semana, minutos, km, RPE, FC y notas.
- Exportación/importación JSON del progreso.
- Recursos oficiales de Rollerblade y búsquedas de vídeo por técnica.
- Responsive para móvil.
- Sin dependencias.

## Vercel
Importa el repositorio y deja Framework Preset = Other, Build Command vacío y Output Directory `.`.
