# Return to Skating — 13 semanas

Web estática para acompañar un programa 645 de Amoila Cesar con sesiones de patinaje por la tarde.

## Características

- 13 semanas.
- 6 días de trabajo + 1 día de recuperación por semana.
- Progresión: readaptación → frenado → stride → crossover → backwards → control de velocidad → potencia → resistencia → urban básico → velocidad submáxima → integración → evaluación.
- Cada sesión tiene duración y ejercicios.
- Casillas de progreso guardadas en `localStorage`.
- Búsqueda de vídeos por técnica en YouTube.
- Biblioteca oficial de vídeos de Rollerblade.
- Diseño responsive para Android.
- Sin frameworks ni dependencias: se puede subir directamente a GitHub Pages o Vercel.

## Despliegue en Vercel

1. Crea un repositorio en GitHub.
2. Sube `index.html`, `styles.css`, `app.js`.
3. En Vercel: Add New Project → Import Git Repository.
4. Framework Preset: Other.
5. Build Command: vacío.
6. Output Directory: `.`.
7. Deploy.

## Nota

Los enlaces de YouTube son búsquedas guiadas, no vídeos individuales, para reducir el riesgo de que un vídeo concreto desaparezca o cambie. La biblioteca oficial de Rollerblade se incluye como referencia adicional.

## Uso

Abre la semana correspondiente, completa las tareas y marca cada ejercicio. El progreso queda guardado en el navegador del dispositivo.
